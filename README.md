## Enterprise modernization

Before founding Shimizu Technology, I progressed from Junior Software Engineer
to Software Engineer and Ruby Team Lead at **Spectrio** (Dec 2021-Jan 2025).
Spectrio brought me back from Sep 2025-Feb 2026 for a six-month contract
engagement leading critical modernization work across legacy Rails systems.

During that return engagement, I upgraded applications through **Ruby 3.3.4**
and **Rails 7.2.3**, modernized Webpack and CI/CD infrastructure, resolved
Heroku and asset-pipeline compatibility issues, reduced one deployment slug by
approximately **1.8 GB**, and coordinated database migration and production
rollout work. It is a good example of how I work: understand a risky legacy
system, build a practical upgrade path, lead the team through it, and leave the
production environment more stable and maintainable.

## Selected work

### [Cornerstone Payroll](https://github.com/Shimizu-Technology/cornerstone-payroll)

A Guam-native payroll and firm-operations system covering payroll calculation,
approvals, check printing, pay stubs, tax reporting, adjustments, audit history,
and role-based access. Built with Rails 8, React 19, TypeScript, and PostgreSQL.

### [Code School of Guam Learning Platform](https://github.com/Shimizu-Technology/csg-learning-platform)

The learning and operations hub behind Code School of Guam: curriculum,
cohorts, lesson scheduling, progress, grading, student support, messaging, and
mobile communication. Rails, React, React Native, Clerk, and PostgreSQL.

### [HåfaGPT](https://github.com/Shimizu-Technology/HafaGPT)

An AI-powered Chamorro language learning platform combining FastAPI, React,
PostgreSQL, retrieval-augmented generation, language-content tooling, and model
evaluation. Live at [hafagpt.com](https://hafagpt.com).

### [Håfa Recipes](https://github.com/Shimizu-Technology/hafa-recipes)

A mobile recipe library that turns cooking videos, websites, photos, and
handwritten family recipe cards into structured recipes. Built with FastAPI,
React Native, Expo, PostgreSQL, AI extraction, OCR, and an iOS app.

### [Marianas Open](https://github.com/Shimizu-Technology/marianas-open)

The live multilingual platform for an international martial arts tournament
series, with events, competitors, rankings, galleries, video, sponsors, admin
workflows, analytics, and search. Rails, React, TypeScript, and PostgreSQL.

### [Media Tools](https://github.com/Shimizu-Technology/media-tools-api)

A Go, React, and SwiftUI product for video and audio transcription, PDF
extraction, cited AI summaries, chat, background processing, collections, and
webhooks. [Try the web app](https://media-tools-gu.netlify.app).
